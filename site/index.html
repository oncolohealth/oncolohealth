Contribute

Built to grow with every lab.

Share a model or dataset as a link to your files, a zip, a Hugging Face page or a Zenodo record. We check it the same way we check everything else, then it joins the catalog so the next researcher can build on it.

  1. 1Describe it: what it is, the scan type and body part, the license.
  2. 2Link the files. We never host patient data, and identifiable data is refused.
  3. 3It enters the catalog as cataloged, held for review. It only climbs the evidence ladder when we reproduce it.
