# Project context and next steps

## Accepted direction

- Serve researchers, students, and model developers first.
- Preserve reasoning, coding, research, and reliable tool use in the coordinator.
- Connect specialized models through explicit compatibility checks and inspectable results.
- Support direct specialist use, transfer learning, and permitted teacher-guided distillation.
- Make dataset discovery, evidence review, reliability assessment, and training assistance core features across all three paths.
- Give the assistant auditable internet research tools and source-linked explanations.
- Begin with bone X-rays. Lung CT, brain MRI, pathology, and genomics are later branches with separate scientific endpoints.
- Aim for performance competitive with strong methods on named tasks. Measure the whole pipeline, including routing errors, uncertainty, and failure cases.
- Reuse existing models and infrastructure where suitable; investigate permissions for inference, adaptation, and distillation separately.
