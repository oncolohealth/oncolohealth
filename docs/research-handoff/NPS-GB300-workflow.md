# Public computing workflow reference

The original public [GB300 user-guide index](https://gitlab.nps.edu/hpc/gb300-documentation/-/tree/master/User%20Guides?ref_type=heads) and [access guide](https://gitlab.nps.edu/hpc/gb300-documentation/-/blob/master/User%20Guides/README.md?ref_type=heads) are the primary references. Actual credentials, project/account choices, quota, mounts, GPU/runtime compatibility and network/MFA reachability must be verified by the authorized execution owner. Private account and dashboard details are excluded from this handoff.

The source archive includes draft operational scripts with generic placeholders. They have not been executed on NPS. Login-node SSH and tool/browser tunnels are distinct from direct SSH into a workload. Training needs an agreed program/container, persistent storage, exact resource/time limits, a checkpoint destination and explicit execution scope. No launch command or job allocation is certified by this document.
