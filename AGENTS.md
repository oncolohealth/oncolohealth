## Team Hub

The team coordinates in the Google Doc **Cancer AI Research — Team Hub**:
https://docs.google.com/document/d/15NZoxoJoxgVSUdxn5RBD7qvqjMuigAJ_Xu2MFSK_3bA/edit

It holds the project snapshot, task assignments (T01–T04), open questions, the model register, recorded decisions, and a "Local build checklist" tab that tracks this repository. Read it before proposing changes to shared direction. When editing it, change only your own check-in or claimed task and keep other contributors' writing intact.

### Keep it up to date

When work in this repository changes its progress, update the Team Hub's "Local build checklist" tab to match, in the same session:

- Move items between **Done**, **In progress** and **Next** as their state changes, and add new items when work starts or a next step is identified.
- Update the facts it quotes (test count, artifacts downloaded and storage used, catalog size, dataset findings) when they change.
- Keep [PROGRESS.md](PROGRESS.md) and the checklist tab consistent; neither should claim more than the other.
- Report software progress only. Never describe synthetic or software results as medical findings.
- Read the current tab before editing, change only that tab, and keep other people's edits intact. Other sections of the Hub belong to their authors.
